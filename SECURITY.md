# Security Policy

## Supported Versions

The following versions of the Odoo Business Intelligence & Decision Support System are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 18.0.x  | :white_check_mark: |
| < 18.0  | :x:                |

## Reporting a Vulnerability

Please report any security vulnerabilities or credentials disclosure privately to the repository owner **@Arilano14**.

Do NOT create public GitHub issues for security vulnerabilities.

### Vulnerability Reporting Process
1. Send a private message or security advisory report to `@Arilano14`.
2. Include full details of the vulnerability and steps to reproduce.
3. The maintainer will respond within 48 hours to acknowledge receipt and coordinate a patch.
